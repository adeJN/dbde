# DBde 0.2.3

Pembaruan untuk macOS Apple Silicon (M1 dan generasi berikutnya).

- Copas banyak tabel lintas koneksi MySQL/MariaDB/TiDB dengan progress, validasi jumlah record, dan pemetaan foreign key.
- SQL editor dengan pilihan query, autocomplete alias tabel, pengaturan editor, dan format yang dapat di-undo.
- Panel laporan proses dan notifikasi hasil untuk copy, transfer, import, export, dan aksi lainnya.
- Perlindungan transaksi saat menutup tab atau koneksi, termasuk ketika status transaksi tidak dapat diperiksa.
- Refresh pada jendela query terpisah menjalankan SQL terakhir yang berhasil, termasuk bagian yang dipilih.
- Pesan timeout dan pembatalan query yang lebih akurat; notifikasi lama dibatasi dan dikelompokkan agar memori tetap terkendali.
- Perapian dialog import, konfirmasi hapus koneksi, dan posisi pesan daftar tabel kosong.

Simpan perubahan dan selesaikan transaksi sebelum memasang pembaruan. Copas mengambil snapshot per tabel; trigger, routine, dan hak akses tidak termasuk dalam salinan tabel.

Untuk instalasi manual, unduh file `.dmg`. Pengguna versi lama yang mendukung updater dapat membuka **App updates** untuk memperbarui aplikasi.
